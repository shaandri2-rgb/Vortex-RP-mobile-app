# VORTEX RP Mobile App

Android application project for the VORTEX RP community.

## Build

The GitHub Actions workflow builds a debug APK and verifies that the APK file itself is at least 30 MiB before uploading it.

## Included in this build

- Native Android app shell with Home, Forum, Store, Gallery, Discord and Profile sections.
- Eleven high-resolution, offline VORTEX-themed wallpapers.
- Wallpaper gallery with previous/next controls and saving to Pictures/VORTEX RP on Android 10+.

## Not connected yet

The server status, member accounts, forum backend, store checkout/payment processing and Discord invite are not connected. This APK is not a GTA/SA-MP game client. Do not enter payment details or passwords into placeholder screens.
